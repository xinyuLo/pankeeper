# PanKeeper 使用说明

PanKeeper 是一个自托管的网盘转存管理工具，把「聚合搜索 → 转存到自己的网盘 → 媒体库刮削 → 生成 STRM → 刷新 Emby」串成一条自动流水线。本文按界面菜单逐页介绍功能与操作；部署方法见 [README](../README.md)。

> 文中界面文案以当前版本为准（v0.1.x）。百度网盘 / 夸克网盘 / 115 网盘下文统称「三网盘」。

## 1. 界面总览

登录后左侧是主导航（手机端在底部标签栏），按四个分组组织：

| 分组 | 页面 | 作用 |
| --- | --- | --- |
| — | 首页 | 网盘连接状态与定时任务总览 |
| 转存中心 | 搜索转存 | 聚合搜索资源并手动转存 |
| 转存中心 | 转存配置 | 给每个网盘配置常用转存目录与联动规则 |
| 自动转存 | 百度网盘 / 夸克网盘 / 115 网盘 | 每个网盘的定时自动转存任务 |
| 日志管理 | 搜索历史 | 全部转存记录台账 |
| 日志管理 | 转存历史 | 自动任务的每一次执行记录 |
| 日志管理 | 推送历史 | Server 酱等推送的发送记录 |
| 日志管理 | 请求日志 | 发往各网盘的请求量统计 |
| 系统管理 | 网盘连接 | 添加 / 管理网盘账号（Cookie） |
| 系统管理 | 缓存配置 | 网盘目录树缓存与一键预热 |
| 系统管理 | 队列配置 | 转存队列的执行节奏 |
| 系统管理 | 系统设置 | 搜索源 / 代理 / 推送 / 联动 / 账号安全 |

- 顶栏右侧可切换日间 / 夜间主题；侧栏底部「退出登录」。
- 手机端（宽度 < 768px）底部是五个标签：`首页`、`搜索`、`记录`、`自动`、`更多`。其中「记录」「自动」点开是子菜单，「更多」面板里有全部系统管理入口。
- 转存提交后只是**入队**，实际进度和日志在页面右下角的「队列抽屉」里实时查看。

## 2. 五步上手

1. **登录**：首次部署的默认账号为 `admin / admin#123`，登录后立即到「系统设置 → 账号安全」修改用户名和密码。
2. **网盘连接**：到「系统管理 → 网盘连接」粘贴 Cookie，添加至少一个网盘账号。
3. **搜索源**：到「系统设置 → 搜索源」填写 PanSou 服务地址并「测试连通」——搜索结果全部来自 PanSou，没配它搜索永远是空的。
4. **转存配置**：到「转存中心 → 转存配置」给网盘账号添加常用目录（别名 + 网盘路径），并按需开启 QMS / LitePan 联动。
5. **开始转存**：搜到资源点「快速转存」直接入队；追更类资源到「自动转存」建一个定时任务，之后完全不用管。

> 媒体库联动需要外部服务：QMS（qMediaSync）或 LitePan 二选一，在「系统设置 → 联动后端」里配置。不配置也能正常登录和转存，只是刮削 / STRM 环节不会触发。

## 3. 首页

一屏看清三件事：

- **顶部问候横幅**：按时间问候 + 现状摘要（几个网盘已连接、几个任务最近失败、下次触发时间与倒计时），右侧「搜索」「定时任务」两个快捷入口。
- **网盘状态**：百度 / 夸克 / 115 三张卡片，各有连接状态（`连接正常` / `凭据已失效` / `未配置`）、会员标识、容量进度条、最近一次执行简报（`新增 N · 跳过 N · 失败 N`）。点卡片切换下方任务列表，点「去管理」进入对应网盘的自动转存页。
- **定时任务**：按网盘 tab 展示任务与下次触发时间，有失败任务时 tab 上会出现红点。空状态可直接「新建一条」。

## 4. 搜索转存

转存中心的核心页面：输入片名 / 关键词，聚合搜索全网分享资源，按网盘自动分类，一键转存。

### 4.1 搜索

- 顶部搜索框支持空格分隔多个关键词，回车或点「搜 索」触发。
- 结果按网盘分类到 tab（顺序：百度、夸克、115、磁力、123、阿里、迅雷、UC），顶部统计卡可点击，等效切换筛选。
- 同网盘内结果按画质加权排序——4K / 1080P、REMUX / WEB-DL、杜比视界 / 全景声、H.265 等规格越高越靠前。
- 搜索源右上角有引擎状态胶囊（`检索引擎在线` / `离线` / `未配置`），离线时先去「系统设置 → 搜索源」检查地址。
- 离开页面再回来，上一次的搜索词和结果会自动还原。

### 4.2 支持的范围

| 资源类型 | 能做什么 |
| --- | --- |
| 百度 / 夸克 / 115 | 快速转存、普通转存（需先配好该网盘账号与转存目录） |
| 磁力链接 | 「复制磁力」，由你自行处理 |
| 123 / 阿里 / 迅雷 / UC | 仅展示结果，暂不支持直接转存 |

### 4.3 死活预检

点击任一转存按钮时，系统会先自动检测分享链接是否还有效：有效则打开转存弹窗；已失效会直接拦截并提示原因，不入队。磁力链接跳过检测。

### 4.4 快速转存

两三步完成转存，适合大多数场景：

1. **保存位置**：下拉选择「转存配置」里给该网盘配好的目录（标了「默认」的会自动选中）。
2. **文件夹更名**（可选）：留空则用资源名新建文件夹；右侧⚡「识别」按钮可调 TMDB 智能识别，一键回填「标题 (年份)」。
3. 点「开始转存」入队。弹窗下方有「转存后」路径预览，以及本次会触发的联动（QMS 刮削 / STRM 生成 / LitePan 推送）。

行为细节：

- 快速转存**固定建壳**：在所选位置下新建一个文件夹承接分享内容（剥壳平铺转入），不会把文件散落在目标目录根下。
- **电视节目类目录**全部转存，无需勾选；**电影类目录**检测到多个文件时会出现勾选列表（默认只列出视频文件），可以只挑正片。
- 检测中的四态提示：`正在检测资源…` → 检测通过（单一资源直接转 / 多文件进入勾选 / 电视节目全转）或 `文件清单获取失败——链接可能已失效，无法转存`。
- 入队成功提示当前排队位次；同一分享已在队列中时不会重复入队。

### 4.5 普通转存

需要精细控制时用「转存」按钮，弹窗分左右两栏：

- **左栏「分享内容」**：拉取分享文件清单，逐个勾选要转存的文件（点过「查看文件」的分享会秒开）。开启「过滤其他文件」后，非视频文件会显示但置灰禁选。
- **右栏「目标位置」**：懒加载的网盘目录树，逐级展开点选目标目录。
- **文件夹更名**：留空 = 不建壳，勾选内容直接平铺进目标目录；填了 = 新建该名称文件夹（壳）承接内容。
- **联动设置**（按系统选的联动后端显示）：
  - QMS：开关「联动 QMS」（默认开）+「过滤其他文件」+「子目录」；开着时出现**刮削目录下拉**，默认按目标位置自动带出——QMS 整理成功后自动生成 STRM，失败不生成。
  - LitePan：开关「联动 LitePan」+ **事件名输入框**，须与 LitePan 自动化规则里配的事件名一致；留空则按「转存配置」里该目录配的事件。
- 底部实时显示 `已选 X/Y 个文件 · 共 Z`；检测未通过或未勾文件时「开始转存」禁用。

> 「目录跟随」：切换目标目录时，联动选项会按「转存配置」自动匹配；一旦手动改过就不再自动跟随，下次打开弹窗恢复默认。

### 4.6 TMDB 识别

两个转存弹窗的「识别」按钮都走 TMDB：

- 唯一高置信结果直接回填「标题 (年份)」；存疑会明确提示请确认。
- 多个候选（比如同名电影和剧集）会弹出候选卡片（海报 / 年份 / 类型 / 简介），点一张回填。
- 依赖「系统设置 → 代理配置」里的 TMDB API Key。

### 4.7 搜索频道设置

搜索框下方「✎ 管理」可打开「搜索频道设置」：勾选白名单频道，搜索时只扫这些源（更快）；不勾任何频道 = 使用 PanSou 的全部频道。白名单保存在后端设置。

## 5. 转存配置

页面口号：给每个网盘配一套自己的「别名 → 路径」。配好后搜索结果里的「快速转存」可直接下拉选择，不必每次翻目录树。**配置按账号隔离——同一网盘的不同账号互不影响。**

### 5.1 管理目录

- 顶部百度 / 夸克 / 115 三个 tab，徽章显示各自已配目录数；「+ 新增目录」打开编辑弹窗。
- 列表里可「设为默认」（快速转存的默认选中项）、「编辑」、「删除」。每个账号下的第一条目录新增时自动成为默认。

### 5.2 目录字段

| 字段 | 说明 |
| --- | --- |
| 名称 / 类型 | 名称出现在快速转存下拉框里（≤20 字）；类型选「电影」或「电视节目」，决定快速转存的行为——电影目录多文件时可勾选只转正片，电视节目目录照旧全部转存 |
| 网盘 / 所属账号 | 三选一；账号在「网盘连接」页添加 |
| 网盘路径 | 点「浏览」打开懒加载目录树选择 |
| 排序 | 数字越小越靠前，快速转存下拉按此排序 |
| 过滤其他文件 | 默认开。开启后转到此目录只保存视频文件（推荐） |
| 联动 QMS | 仅联动后端 = QMS 时显示。开启后转到此目录的资源自动送 QMS 刮削整理，需选一个「QMS 整理目录」；整理成功后自动生成 STRM |
| 联动 LitePan | 仅联动后端 = LitePan 时显示。开启后转存完成时推 Webhook 给 LitePan，需填「LitePan 事件名」——须与 LitePan 自动化规则里配的事件名完全一致；不同目录可配不同事件（电影 / 电视剧各推各的规则） |

## 6. 自动转存

「自动转存」分组下每个网盘一页（`百度网盘` / `夸克网盘` / `115 网盘`），管理「分享链接 → 定时自动转存到我的网盘」的任务。适合追更：资源主持续更新分享链接里的内容，任务到点自动检查并把新增文件转进来。

### 6.1 任务列表

- 工具栏：「＋ 新增任务」「立即检查全部」。
- 每行显示：任务名、启用开关、分享链接（附提取码徽章 + 查看文件 / 打开网盘 / 复制链接）、定时策略（人类可读，如 `每天 03:00`）、已排除数、上次执行、最近结果（`成功` / `部分失败` / `失败` / `执行中` / `从未执行`，附 `新增 N` 统计）。
- 行操作：`立即执行`（▶，打开执行监控）、`编辑任务`、`排除清单`、`执行详情`、`转存日志`、`重新触发 QMS`（仅最近一次是「部分失败」即可用，先清掉 QMS 侧失败记录再重刮，配了 STRM 会自动续上）、`删除任务`。

### 6.2 新建 / 编辑任务

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 必填 |
| 所属账号 | 多账号时选择；「默认」在「网盘连接」页设置 |
| 分享链接 | 粘贴分享链接；末尾带 `?pwd=` 会自动识别提取码。点「解析」可校验链接并预览文件数 |
| 提取码 | 只读，解析后自动填写 |
| 保存到 | 点「浏览」选网盘目录 |
| 对比路径 | 可选。转存前与该目录下的文件做**去重对比（先 MD5 后文件名）**，重复即跳过——多季追更建议指向上级目录 |
| 包含子目录 | 默认勾选，分享内有子目录时一并转存 |
| QMS / LitePan 联动 | 与转存配置同款：QMS 可选刮削目录与 STRM 同步目录（转存 → QMS → STRM，触发间隔 15 秒）；LitePan 填事件名 |
| 正则过滤 | 留空不过滤；填了模式（如 `\.mkv$`）只转存文件名命中的文件 |
| 定时表达式 | 标准 5 位 cron（分 时 日 月 周），默认 `0 3 * * *`（每天凌晨 3 点）。点「选择」打开可视化定时策略：每天 / 每周 / 每小时 / 每 N 分钟 / 自定义，底部实时预览 |

保存后任务默认启用，到点由后台队列自动执行。

### 6.3 排除清单

任务行的「排除清单」按钮维护**文件级黑名单**：勾中的文件每次转存都被跳过。

- 候选列表 = 正则命中的文件 + 已勾选的排除项。
- 「一键勾选无 MD5」：无校验值的文件转存时只能按文件名去重（最容易误判重复），最值得排除。
- 清单在每次转存执行后自动刷新；已排除但当前清单里没有的文件，点「确定」会移出排除清单。

### 6.4 执行与历史

- **立即执行**：打开「执行监控」弹窗，实时显示 `新增` / `跳过` / `失败` / `已排除` 四个统计与滚动日志，状态会依次走过入队 → 转存 → 触发 QMS → 生成 STRM → 执行完成。
- **转存历史**（日志管理分组）：所有自动任务执行记录的总表，可按任务 / 网盘 / 状态 / 关键词筛选。统计含 `新增` `跳过` `失败` `分享` `正则未命中` `MD5 跳过`；点「详情」能看到正则过滤后的文件、命中排除清单的文件、MD5 去重跳过的文件、本次实际转存的**逐文件清单**与完整执行日志。
- 「清空记录」下拉支持按时间范围（一个月 / 三个月 / 半年前）或全部清空。

## 7. 日志管理

### 7.1 搜索历史

名字叫「搜索历史」，实际是**全部转存的记录台账**：每一笔转存（搜索 / 快速 / 普通 / 自动）完成后都会落一条记录。

- 筛选：状态（`完成` / `部分失败` / `链接失效` / `失败`）、网盘、资源名称关键词。
- 每条记录：来源网盘、目标位置、结果（如 `完成 36/36`）、整理（QMS 状态，LitePan 后端显示「LitePan 接管」）、STRM 状态、时间；操作有 `详情` / `触发` / `删除`。
- **详情抽屉**：分享链接（含提取码）、保存路径、完成后动作、执行日志，底部可「重试失败项」「再次触发 QMS」「删除记录」。
- **触发**：按该记录的联动后端重新触发一次刮削 / 推送，不用重新转存。
- 筛选条上的「触发 QMS / STRM」是手动补救入口：选择 QMS 刮削目录 / STRM 目录直接触发（可只选一个；两个都选时 STRM 延迟 15 秒自动跟上）。

### 7.2 转存历史

见 [6.4 执行与历史](#64-执行与历史)——自动任务每一次执行的记录与逐文件明细。

### 7.3 推送历史

每一条**实际发出去的推送**（Server 酱 / 自定义 Webhook）都有记录：时间、成败、分类（`搜索转存` / `自动转存` / `凭据过期告警` / `通知`）、失败原因。点「详情」按 Markdown 渲染 Server 酱实际收到的正文（标题 / 海报 / 链接）。支持按时间范围清空。

### 7.4 请求日志

统计 PanKeeper 每天发往各网盘的 HTTP 请求量，帮你避免因请求过密触发网盘风控：

- 三张网盘卡片给出今日量级：`正常`（≤150 次/天）、`偏多`（151–400）、`频繁`（>400，有风控风险）。
- 折线图可切换近 7 / 30 / 90 天。
- 统计口径：只算 PanKeeper 自己发的请求（探活、检测连通、转存全过程），你在网盘网页 / App 里的手动操作不计入。
- 每日探活会自动跳过当天已有请求的网盘——那次请求本身就证明了凭据有效。
- 统计默认保留 180 天。

## 8. 系统管理

### 8.1 网盘连接

添加和管理三网盘的账号（Cookie 凭据）。

**添加账号**：右上角「＋ 新增网盘」→ 选平台 → 可选填账号别名（区分同平台多账号）→ 粘贴整串 Cookie → 「保存并验证」。Cookie 获取方式（界面原文）：

> 登录网盘网页版 → 按 F12 打开开发者工具 → 网络 标签 → 刷新页面 → 点任一请求 → 在请求头里复制完整 Cookie。凭据加密存储，任何接口都不会回显明文。

保存后会立即连接网盘验证，通过后自动预热该网盘的目录树。

**账号卡片**：

- 状态标签：`正常` / `已失效` / `未配置`；同平台多账号可点「★ 默认 / ☆ 设默认」切换默认账号（转存与定时任务未指定账号时用它）。
- 信息行：会员标识与到期日、上次检测时间、**默认根目录**（所有目录树弹窗的浏览起点）、**失效通知**开关（开启后该账号凭据失效会推送告警）。
- 容量条：已用 / 总量，≥80% 黄、≥95% 红。
- 操作：`配置凭据`（换 Cookie）、`检测连通`、`删除`。
- 后端每日自动探活一次（默认 10:00），发现凭据失效会推送告警，按提示回来重新贴 Cookie 即可。

### 8.2 缓存配置

缓存的是**网盘的目录树**：转存弹窗的目录树、快速转存的路径建议都直接读这份缓存，不实时打网盘接口，打开秒出。

- **缓存预热**：一键把所有已连接账号的目录树逐个排队预热（串行跑，同网盘多账号也不并行，避免触发风控），页面实时显示进度。大网盘可能需要几分钟到十几分钟。
- **缓存策略**：目录树缓存开关（默认开）、持久化（默认开，重启不丢）、缓存失效时间（默认 30 小时）、自动刷新（默认开）。
- **内存保护**：缓存占用超阈值（默认 85%）后按「降级动作」自动降级；可设缓存大小上限（默认 200 MB）。
- **已缓存目录表**：每个账号的缓存时间、下次刷新倒计时、条数、大小，可单行「刷新 / 清除」。

### 8.3 队列配置

所有转存都进队列慢慢跑，这里决定**跑多快、什么时候触发后续动作**。改完即时生效，正在执行的任务不受影响：

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| 线程数 | 1 | 同一时刻最多并行执行的任务数（1–4） |
| 转存触发间隔 | 5 秒 | 两个任务开始之间的最小间隔 |
| QMS 触发时间 | 10 秒 | 转存完成后等多久触发 QMS 刮削 |
| STRM 触发时间 | 10 秒 | QMS 完成后等多久触发 STRM |

页面底部会实时拼出当前节奏摘要。另外每个网盘适配器内置了**每账号限速闸与连败熔断**，无需配置，用于避免触发平台风控。

### 8.4 系统设置

所有改动**自动保存**；敏感项（API Key 等）回显为 `****` + 末 4 位。

**搜索源**

- `PanSou 地址`：聚合搜索服务地址，带「测试连通」与在线状态（响应耗时 / 插件数）。
- `请求超时`：默认 30 秒；`结果缓存`：默认开启。

**代理配置**（TMDB 连通）

- `TMDB API Key`：[themoviedb.org](https://www.themoviedb.org/) 免费申请，用于识别与推送封面，带「测试连通」。
- `连通模式`：`代理模式`（填 HTTP / SOCKS5 代理，留空直连）或 `Host 模式`（按域名直连指定 IP，同域名多行按顺序择优，测试后自动把最快 IP 置顶）；自建反代证书对不上时可开「跳过证书校验」。

**推送通知**

- `启用推送`：总开关，默认关。
- `Server 酱 SendKey`：从 Server 酱官网获取，可「发送测试」。
- `自定义 Webhook`：可选，推给自己的机器人。
- `推送时机`：三个独立开关——`自动转存`、`搜索转存`、`凭据过期告警`（默认全开）。

**联动后端**

- 二选一：`QMS 全流程`（刮削 / STRM / 刷新 Emby，由 PanKeeper 跟踪结果，默认）或 `LitePan`（转存完成 Webhook 通知，后续整理由 LitePan 自理）。
- QMS：填 `QMS 地址` + `API Key`，开启联动前会强制测连通；`触发动作`可选`刮削后生成 STRM`、`完成后刷新 Emby`。
- LitePan：填 `Webhook 地址`（LitePan 自动化事件接口）+ `API Key`（LitePan「API Key」页生成）+ `通知来源`（选填，**LitePan 规则按来源精确匹配且区分大小写**）。
- 目录级的联动配置已分散到「转存配置」（每条目录）和自动转存任务弹窗（每个任务），这里只管连接参数与总开关。

**账号安全**

- 改用户名 / 密码（新密码至少 8 位，需验证当前密码，改完强制重新登录）。
- `会话有效期`：1 / 7 / 30 天，默认 7 天。

**头像管理**

- 上传 jpg / png / webp，自动居中裁正并压到 256×256；图片需在约 680 KB 以内。

## 9. 一次转存背后发生了什么

理解这条链路，各页面的配置就能对上号：

```
搜索/快速转存/自动任务
        │  入队（同一分享不重复入队，队列按「队列配置」的节奏跑）
        ▼
 死活预检 → 分享解析 → 文件过滤（正则 / 排除清单 / 只转视频）→ 去重（MD5 + 文件名 + 目录基线）
        │  每账号限速闸 + 连败熔断，避免触发网盘风控
        ▼
 转存到目标目录（建壳 / 平铺 / 勾选 / 子目录）
        │  有新增文件才继续
        ▼
 联动后端
   ├─ QMS：触发刮削整理 → 成功后生成 STRM →（可选）刷新 Emby
   └─ LitePan：POST Webhook（事件 + 路径），LitePan 按规则自行整理
        │
        ▼
 Server 酱推送（带 TMDB 海报 / 简介）→「推送历史」可查
 全程落库：「搜索历史」看结果，「转存历史」看自动任务明细，「请求日志」看请求量
```

## 10. 常见问题与注意事项

**搜索一直是空的？**
先看搜索页引擎胶囊：`未配置` / `离线` 就去「系统设置 → 搜索源」填地址并测试；配了也搜不到就检查「搜索频道设置」是不是把白名单勾空了（勾空 = 全部频道，不是不搜）。

**「快速转存」按钮是灰的？**
两种原因，悬停有提示：该网盘还没在「网盘连接」里配置账号，或该网盘在「转存配置」里一条目录都没有。先去补这两个配置。

**提示「链接可能已失效」？**
死活预检判定分享已失效（可能被举报、取消或需要更高级会员），换一个资源即可；也可能是网盘接口临时抽风，稍后重试。

**QMS / LitePan 联动没触发？**
依次检查：联动后端总开关是否开启且连通（系统设置 → 联动后端）→ 转存目标目录在「转存配置」里是否开了联动 → QMS 刮削目录 / LitePan 事件名是否填了（LitePan 事件名必须与规则完全一致，`通知来源`区分大小写，没填事件名就不联动）。

**网盘账号显示「已失效」？**
Cookie 过期或被平台下线了。到「网盘连接」点「配置凭据」重新贴 Cookie。建议提前打开账号的「失效通知」，失效第一时间收到推送。

**115 提示风控 / 429？**
115 对请求频率敏感，PanKeeper 已内置限速与风控识别，触发后会暂停重试并自愈。此时不要再手动频繁操作该账号，等一会儿即可；长期建议把相关自动任务的执行频率调低。

**数据怎么备份？**
所有持久化状态都在 compose 挂载的 `data/` 目录里（SQLite 主库 + 两把密钥）。备份整个目录即备份一切；**只备份数据库而不备份密钥文件，已保存的网盘凭据将无法解密**——务必整目录一起备。

**升级会丢配置吗？**
不会。配置与记录都在 `data/` 目录，换镜像、重建容器都不受影响。目录树缓存如未开持久化则重启后重建，属于设计如此。
