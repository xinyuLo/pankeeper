# 2026-10-08 批次：转存交互定稿 + 115 风控根修 + 预热队列化 + 勾选转存全跳过根修

> 时段：10-07 深夜 ~ 10-08。前置：10-07 批（179e045）已部署 NAS。

## 一、记录列表整理/STRM 列口径修正（用户实锤"选了 qms 也显示 LitePan 接管"）

- 根因：整理/STRM 列的表头与行内容都跟着**当前全局设置**切（media.backend），历史记录被"现在用哪个后端"覆盖。
- 修：表头固定「整理 / STRM」；行内容按**该条记录自己落库的 backend** 逐行显示（`records` 接口 `_row` 补吐 `backend`；老记录空值回落当前设置）。行级「触发」按钮本就按记录 backend 分流（litepan=重发 Webhook / qms=重触发刮削），不动。

## 二、Server酱不推送根修（用户实锤：电影夹带 nfo/图片，QMS 已整理完但推送静默）

- 根因：等待判定/「未见记录」统计要求**转存清单每个文件**都有 QMS 刮削记录，而 QMS 只整理视频、nfo/图片**永不建记录** → missing 永不归零 → 推送线程干等 30 分钟超时（daemon 线程后端重启即丢）。
- 修：新增视频扩展名白名单 `adapters/base.VIDEO_EXTS`（**11 种，对齐用户清单：mp4/mkv/avi/mov/wmv/flv/webm/m4v/3gp/ts + iso**），等待与「未见」统计只认视频，杂件豁免；纯杂件清单立即放行。快照从「成功 1 / 未见记录 3」变「成功」，信息条不再出「⚠️ N 项未见记录」。

## 三、转存配置「过滤其他文件」开关（2026-10-07 定稿 + 10-08 默认开）

- `DdItem.only_video`（默认**开**，含老库补列默认 1）：开启后转到此目录**只保存视频文件**（VIDEO_EXTS 口径），nfo/海报等杂件转存环节直接剔除，日志记「过滤其他文件：剔除 N 个」并并入排除名单。
- 搜索转存（manual）与自动转存（auto）两路都生效；弹窗显式指定优先于目录配置（见六）。
- 弹窗口径区分（用户定稿）：**快速转存**勾选列表里非视频**直接消失**（含「检测到 N 个文件，过滤 M 个」文案）；**普通转存**非视频**显示但置灰禁选**，开关切换瞬间自动清掉已勾选的非视频路径。

## 四、115 目录浏览"疯狂重试→风控"根修

- 前端 `LazyDirTree.fetchDir` 原来对任何失败盲目重试 3 次（2s 间隔），115 的 302/406 是账号级风控，越打封越久。
- 修：适配器新增 `RiskControlError`（115 的 302 跳风控页 / 406 限频 / 验证码告警），`/files/list` 映射 HTTP **429** + 人话 detail；前端见到 429 **一次都不重试**、直接把人话显示在树上，其余失败重试降为 1 次；600ms 节流改**模块级全局共享**（多弹窗多棵树排队而非并行连发）。

## 五、预热体系重构（用户：多账号要进队列，别并行撞风控）

- 预热改**全局单工队列**：所有 (网盘, 账号) 任务进同一条 FIFO，单 worker 串行消费——3 个百度账号就是排队逐个跑，绝不并行。
- **115 支持预热**（此前白名单只有 baidu/quark），走适配器自带 2s 限速闸。
- 新端点：`POST /cache/trees/warm-all`（全部已连接账号入队）+ `GET /cache/trees/warm-all/status`（队列总览）；`warm`/`status` 支持 acc_id（网盘连接页保存 Cookie 后预热**刚验证的那个账号**，不再固定默认账号）。
- 缓存配置页：新增「**缓存预热**」按钮（确认弹窗→入队→按钮旁实时进度行「预热中 2/5 · 当前：夸克 · 七盘（87 个文件夹）」）；**「立即刷新全部」删除**。
- 网盘连接页：预热进度上**账号卡片**（「正在预热 N 个文件夹…」→「预热完成 · N 个」停留 6s），去掉全局顶部 loading；验证完成立即释放「正在验证 Cookie…」。
- 行内刷新语义修正（用户发现刷新=换皮清除）：**刷新 = 强制实拉网盘并回写缓存**（且只刷该账号**默认根层**，深层交给 TTL/懒加载；缓存键分路径层/fid 层两种形状，loader 按键形状走对分支）；**清除 = 只失效**。

## 八、勾选转存全部跳过根修（用户两连实锤"勾了全跳过"）

- 根因（数据比对定位：缓存清单路径与转存路径完全一致，但过滤全不中）：勾选过滤里 `sel.strip("/")` 只剥了**勾选路径**的前导斜杠、文件路径没剥——`name.mkv != /name.mkv` 永不匹配 → 勾几个过滤几个、全部「未勾选」跳过。

## 九、夸克默认根目录锁定失效（用户实锤"夸克不是从 1.影视 开始的吗"）

- 根因：转存弹窗开树早于 getRootDirs 返回（树按无锁定挂载列出真根），而 LazyDirTree **不监听 rootPath 变化**。
- 修：LazyDirTree 增加 rootPath watch（变了整树按新锁重载）+ TransferModal 等 rootReady 再渲染树（少打一轮真根请求）。
